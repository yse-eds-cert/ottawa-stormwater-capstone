# Cleaned Historical Rainfall Data

This folder will contain cleaned and standardized historical intensity-duration-frequency (IDF) rainfall data for Ottawa.

Data preprocessing will include:

- Checking for missing values and duplicate records.
- Standardizing column names and data formats.
- Verifying rainfall intensity units (mm/hour).
- Organizing rainfall observations by storm duration and return period.

The cleaned datasets will support comparisons between historical and projected rainfall conditions.

Original datasets will remain unchanged in `1_raw_data/1_1_rainfall/`.
