# Cleaned Climate Projections Data

This folder will contain cleaned and standardized climate change-scaled intensity-duration-frequency (IDF) rainfall data for Ottawa.

Data preprocessing will include:

- Checking for missing values and duplicate records.
- Standardizing column names and data formats.
- Verifying rainfall intensity units (mm/hour).
- Organizing projections by emissions scenario, time period, storm duration, and return period.
- Preparing data for comparison with historical rainfall conditions.

The cleaned datasets will support the analysis of projected changes in extreme rainfall and stormwater runoff.

Original datasets will remain unchanged in `1_raw_data/1_2_climate_projections/`.
