# Outputs

**Status: Work in Progress**

This folder will contain the figures, tables, and reports generated throughout the Ottawa stormwater capstone.

Outputs will document the results of rainfall comparisons, stormwater runoff calculations, surface conversion scenarios, and sensitivity analyses.

## Folder Structure

- `4_1_figures/` — Data visualizations, charts, and maps.
- `4_2_tables/` — Summary statistics, calculations, and scenario comparisons.
- `4_3_reports/` — Written analyses, findings, and research summaries.

## Notes

Outputs will be added progressively as the research develops. All results are preliminary until the methodology and assumptions have been evaluated.
