
# Climate Projections Data

This folder will contain original climate change-scaled intensity-duration-frequency (IDF) rainfall datasets for Ottawa.

The analysis will compare projected rainfall conditions for the 2050s under two emissions scenarios.

**Source:** https://climatedata.ca/news/updated-idf-rainfall-data-now-available-on-climatedata-ca/

Datasets will include rainfall intensity, storm duration, return period, and emissions scenario where available.

Original datasets will be preserved without modification.
